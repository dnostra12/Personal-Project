# 국가 온실가스 배출구조 분석 (1990~2023)

Python·Pandas로 국가 온실가스 인벤토리를 전처리하고, MySQL·SQL로 분야별 감소 기여도를 계산한 뒤, 제조업 세부 업종의 1차 감축 검토 대상을 데이터 기준으로 분류한 프로젝트입니다. 결과는 Streamlit 대시보드로 구현했습니다.

## 분석 질문

1. 1990~2023년 국가 온실가스 배출량은 어떻게 변했는가?
2. 2018년 이후 총배출량 감소에 어떤 분야가 크게 기여했는가?
3. 에너지 분야 내부에서는 어떤 세부 분야의 변화가 컸는가?
4. 제조업에서 배출 규모가 크면서 최근 증가하고 있는 업종은 어디인가?

## 주요 결과

| 구분 | 결과 |
|---|---|
| 총배출량 변화 | 1990년 310,566 → 2023년 707,200 kt CO₂-eq (약 +127.7%), 최고점은 2018년 780,140 |
| 2023년 분야별 비중 | 에너지 77.1% · 산업공정 및 제품사용 17.2% · 농업 3.2% · 폐기물 2.6% |
| 2018→2023 감소 기여 | 총배출량 감소분의 94.2%가 에너지 분야 |
| 에너지 분야 내부 | 에너지산업 72.2%, 제조업 및 건설업 14.5%, 기타 10.9% |
| 에너지산업 내부 | 공공 전기 및 열 생산 276,619 → 226,960 kt CO₂-eq (감소 49,659) |
| 제조업 1차 검토 대상 | 화학, 비금속광물 (규모가 크고 2018년 대비 증가) |

공공 전기 및 열 생산의 감소 기여도가 100.2%로 100%를 넘는 이유는, 고체연료 제조 및 기타 에너지 산업의 배출 증가가 감소분 일부를 상쇄했기 때문입니다.

## 분석 흐름

1. **전처리**: 연도별 열로 된 Wide 데이터를 Long Format으로 변환했습니다. 배출량 칸에는 `NO`, `NA`, `IE`, `NE`, `C` 같은 인벤토리 표기값이 섞여 있어, 원본은 `배출량_원본`에 그대로 보존하고 숫자로 변환되는 값만 `배출량`으로 분리했습니다. 표기값을 임의로 0으로 바꾸거나 삭제하지 않았습니다.
2. **중복집계 방지**: 상위 분야 안에 세부 분야가 함께 들어 있어 전체 행을 합산하면 중복됩니다. 국가 단위 분석에는 총배출량, 순배출량, 에너지, 산업공정 및 제품사용, 농업, LULUCF, 폐기물만 추출했습니다.
3. **SQL 분석**: 전처리한 데이터를 MySQL(`ghg_inventory` 테이블)에 저장하고, 2018년과 2023년을 비교해 분야별 증감량·증감률·감소기여도(분야 감소량 ÷ 국가 전체 감소량)를 계산했습니다. 분석 범위는 국가 전체 → 에너지 → 에너지산업 → 세부 배출원 순으로 좁혔습니다.
4. **제조업 스크리닝**: 제조업 및 건설업 세부 업종에 점수를 부여했습니다. 2023년 배출량이 업종 중앙값 이상이면 규모점수 2점, 2018년보다 2023년 배출량이 늘었으면 증가점수 1점이며, 합계가 높은 업종부터 검토 순위를 매겼습니다.
5. **대시보드**: 위 결과를 Streamlit으로 구현했습니다.

## 실행 방법

### 대시보드 (MySQL 불필요)

대시보드는 `data/raw/national_ghg_inventory.csv`만 읽습니다.

```bash
cd PythonProject
uv sync
uv run streamlit run main.py
```

Python 3.14 이상이 필요합니다(`pyproject.toml` 기준). 그래프 글꼴은 `Malgun Gothic`으로 지정되어 있어 Windows 기준이며, 다른 환경에서는 한글 글꼴을 바꿔야 할 수 있습니다.

### 분석 노트북 (MySQL 필요)

노트북의 SQL 단계는 로컬 MySQL에 `ghg_project` 데이터베이스와 `ghg_user` 계정이 있어야 실행됩니다. 비밀번호는 코드에 저장하지 않고 실행할 때 `getpass`로 입력합니다.
